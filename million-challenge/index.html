    百萬大挑戰

    遊戲規則

    1. 共 15 題，每答對一題，獎金往上一階，最高 NT$1,000,000。
    2. 點選答案後，主持人會問「這是最終答案嗎？」，按「最終答案」才會鎖定。（電腦可用鍵盤 A／B／C／D 選答、Enter 確認）
    3. 保底關卡：第 5 題（NT$10,000）與第 10 題（NT$100,000）。答錯時，獎金會掉回最近通過的保底金額（還沒過第 5 題就是 0 元）。
    4. 每題鎖定答案前，都可以按「放棄領獎」，帶著目前已贏得的獎金離開。
    5. 若有開啟計時，時間到視同答錯；使用求救時計時會暫停。

    求救機會（每種限用一次，用過會打叉）：

    • 50:50 刪除：隨機刪去兩個錯誤答案。
    • 👥 現場觀眾求救：顯示觀眾投票百分比。題目越難，觀眾越不可靠！
    • 📞 電話求救：從中醫師、護理師、藥師三位朋友中選一位，通話 30 秒。朋友會說出猜測與把握程度，但不保證正確。
    • 🔄 換題：換成同一關的另一道備用題（題庫該關有備用題時才能用）。

    匯入題目

    把 JSON 或 CSV 內容貼在下面（或選擇檔案），再按「匯入並取代題庫」。題目會存在這台裝置的瀏覽器裡（localStorage），下次開啟仍會保留。

    📖 題目格式說明
    • level：關卡 1–15（1 最簡單，15 是百萬題）。也可改用 difficulty：easy／medium／hard（或 簡單／中等／困難），分別對應第 1–5、6–10、11–15 題。
    • question：題目文字。
    • options：四個選項 [A, B, C, D]（CSV 則用 A、B、C、D 四個欄位）。
    • answer：正確答案，填 A～D（建議）；JSON 也可填數字 0～3（0＝A）。
    • explanation：（選填）答題後顯示的解說。

    同一關放 2 題以上時，每局會隨機抽一題，其餘當作「換題」的備用題。某一關沒有題目時，會自動借用最接近關卡的題目。

    JSON 範例：

    [
  {
    "level": 1,
    "question": "中醫「五臟」不包括下列哪一個？",
    "options": ["心", "肝", "胃", "腎"],
    "answer": "C",
    "explanation": "五臟為心、肝、脾、肺、腎；胃屬六腑。"
  },
  { "difficulty": "hard", "question": "……", "options": ["…","…","…","…"], "answer": "A" }
]

    CSV 範例（第一列是標題；逗號或 Tab 分隔都可以；內容含逗號時請用雙引號包起來）：

    level,question,A,B,C,D,answer,explanation
1,中醫「五臟」不包括下列哪一個？,心,肝,胃,腎,C,胃屬六腑
2,一年有幾個節氣？,12,24,36,48,B,
15,"題目裡有逗號, 要加雙引號",選項1,選項2,選項3,選項4,D,解說

    標題也可以用中文：關卡,題目,A,B,C,D,答案,解說
